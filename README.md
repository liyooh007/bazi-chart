# Bazi — 八字命理引擎（全方位 · 多融合 · 经过验证）

一个**纯标准库**的中式命理计算引擎：从太阳视黄经自算节气，到四柱、大运、
格局用神、神煞、综合断验，全链路可复现、可自检。

```
python -m bazi chart 1990-05-12 14:30 -g 男 --lon 116.4 --years 2024 2035
python -m bazi verify        # 29 项自检
```

---

## 1. 为什么可信

命理工具最怕两件事：**节气算错**（月柱、年柱全盘皆错）和**农历错**（闰月错、
日期漂移）。本项目把这两块做成可量化验证的硬指标：

| 验证项 | 方法 | 结果 |
|---|---|---|
| 节气精度 | 内建 VSOP87D 天文算法 vs **JPL DE441** 数值历表（10 年 × 24 节气 = 240 点） | 1900–2050 年 **≤1 分钟**；2075 年 ≤2 分钟；2100 年 ≤3 分钟 |
| 农历年表 | 202 个农历年界的「月长合计 = 相邻正月日序之差」全量校验 | **零误差** |
| 农历转换 | 1900-01-31 → 2100-12-31 共 **73,000+ 天** 逐日「公历→农历→公历」往返 | **零误差** |
| 春节/闰月 | 12 个已知春节日期 + 9 个已知闰月（1900 闰八、1984 闰十、2023 闰二、2025 闰六、2033 闰十一…） | 全部吻合 |
| 日柱 | 7 个独立锚点（1960 年前后均有）：2000-01-01 戊午、2024-01-01 甲子、2033-01-01 壬子、1900-01-01 甲戌、1900-10-23 己巳、1949-10-01 甲子、2033-01-31 壬午 | 全部吻合 |
| 命例复现 | 乾隆 1711-09-25 子时、蒋介石 1887-10-31 午时、毛泽东 1893-12-26 辰时、周恩来 1898-03-05 辰时 | 四柱与公开命盘**逐字一致** |
| 随机一致性 | 400 个随机命盘的不变式（年柱递推、五行归一、喜忌互斥、大运步进、JSON 可序列化） | 全部通过 |

数据来源与采集脚本见 `bazi/tools/fetch_reference.py`（节气/农历取自公开历算站点
的 DE441 定气结果，采集过程全程在页面上下文取数，无人工转录）。

> 说明：2050 年以后的分钟级偏差来自 **ΔT（TT−UT1）外推模型的分歧**——不同机构对
> 未来 ΔT 的预测本身就相差分钟量级；黄经级数本身的精度远高于此。对命理应用而言，
> 节气边界的分钟级不确定性只影响"恰好生在交节前后几分钟"的极端个例。

## 2. 快速开始

```python
from bazi import BaziChart

c = BaziChart(1990, 5, 12, 14, 30, gender="男", longitude=116.4, name="张三")

print(c.four_pillars.ganzhi)      # 庚午 辛巳 丁丑 丁未
print(c.pattern.name, c.pattern.yongshen)      # 正财格 火
print(c.lunar_date)               # 庚午年四月十八
c.liunian_table(2024, 2035)       # 流年表（含十神、大运、标记）
c.good_years(2024, 2035)          # 用神当值之年
print(c.report(years=(2024, 2035)))            # 中文命书
data = c.to_dict()                # 结构化数据（JSON 友好）
```

### 命令行

```bash
python -m bazi chart 1990-05-12 14:30 -g 男 --lon 116.4 --name 张三
python -m bazi chart 1990-05-12 14:30 --json > pan.json      # 供程序消费
python -m bazi chart 1990-05-12 14:30 --sections 事业 财运     # 只看指定段落
python -m bazi poem 1990-05-12 14:30 -g 男                  # 命理诗（前途/命运/好坏）
python -m bazi poem 1990-05-12 14:30 --json                 # 诗 + 逐句注解（JSON）
python -m bazi terms 2025                  # 2025 年 24 节气（精确到秒）
python -m bazi lunar 2025-01-29            # 公历 → 农历
python -m bazi solar 2033 11 1 --leap      # 2033 闰十一月初一 → 公历
python -m bazi verify                      # 自检
```

`chart` 常用参数：`-g/--gender`、`--lon`（东经为正，自动换算**真太阳时**）、
`--tz`（时区，默认 +8）、`--rollover zi|midnight`（日柱 23 点换日 / 0 点换日）、
`--years START END`、`--json`、`--brief`、`--sections`。

## 3. 排盘规则（与主流排盘软件一致）

| 项目 | 规则 |
|---|---|
| 年柱 | **立春**换年（非正月初一），例：2024 立春 02-04 16:26:53 |
| 月柱 | **节**换月（立春、惊蛰…小寒）；月干用**五虎遁**（甲己之年丙作首） |
| 日柱 | 儒略日数连续推：(JDN + 49) mod 60；默认 **23:00 换日**（晚子时归次日） |
| 时柱 | **五鼠遁**（甲己还加甲）；子时自 23:00 起 |
| 真太阳时 | 标准时 + (经度 − 时区中央经线)×4 分钟 + **均时差**（实测 ±16.4 分钟与天文值一致） |
| 起运 | 阳男阴女顺排、阴男阳女逆排；**3 天 = 1 岁**，1 天 = 4 月，1 时辰 = 10 天 |
| 流年 | 以立春为界；流月由流年干五虎遁、以节换月 |

## 4. 体系覆盖

**基础**：天干地支、阴阳五行、生克、藏干（本气/中气/余气 + 权重）、十神（含
六亲简称与五类归组）、纳音（60 甲子 30 音）、旬空（空亡）、十二长生、生肖星座。

**关系**：天干五合四冲、地支六合六冲六害、三合局、三会方、半合、三刑与自刑、伏吟。

**量化**：
* 五行力量 —— 天干/地支宫位权重（月支 1.6、日支 1.2、年支/时支 0.8）× 藏干权重，
  再叠加月令当权（当令 ×1.2、被月令克 ×0.85），归一为百分比
* 日主旺衰 —— 印比（生扶）与财官食伤（克泄耗）占比 + 得令失令 + 通根判定
* 十神分布、大运吉凶评分（干支对用忌神、冲刑合害月令/日支）

**格局**：禄刃格 → 透干取格 → 月令本气取格；变格含专旺（曲直/炎上/稼穑/从革/润下）、
从格（从财/从杀/从儿/从势）、化气格。

**用神**：扶抑为主 + 寒暖燥湿**调候**修正 + 两神交战**通关**修正；输出用神/喜神/
忌神/仇神/闲神五行，并映射到十神。

**神煞 40+**：天乙、太极、福星、国印、文昌、金舆、禄神、羊刃、天德、月德、
将星、华盖、驿马、桃花、劫煞、灾煞、亡神、孤辰、寡宿、天罗、地网、天医、
魁罡、金神、十恶大败、阴差阳错、六秀日、日德、天赦、三奇、红艳、童子煞……
每条均带查法依据与吉凶权重（评分可正可负），并支持流年十二神（太岁/岁破/白虎…）。

**大运流年**：10 步大运（干支、十神、长生、起止年龄/年份、吉凶评分）、流年
（含岁运并临、伏吟、用忌神到位标记）、流月、逐年运势要点。

**命理诗**（`bazi.poem`）：据命盘实算要素生成**七言八句**律诗，二/四/六/八押韵，
并逐句给出"这句对应命盘哪里"的注解：

* 八句结构：起（日主气象）→ 承（月令寒暖、格局旺衰）→ 转（用神取向、前程方略）
  → 合（神煞助缘、大运早中晚走势）→ 结（总断与劝勉）
* **切命不切空**：`丁火灯窗夜向晨`（日主丁）、`寒天喜火暖元神`（子月冬生需调候）、
  `功名有路凭木引`（官杀为主、用神在木）、`中年发迹晚尤昌`（大运先抑后扬）
* **韵随命变**：≥80 分用人辰辙（开朗）、65–79 庚青辙（清朗）、55–64 东钟辙（厚重）、
  45–54 一七辙（收敛）、<45 由求辙（沉缓）
* **确定性**：同一八字固定成诗（以四柱干支作种子），`variant` 可取其它成稿
* 诗库 700+ 成句，由 `verify_library()` 强制校验"必为 7 字 + 偶句入韵"

**命局综合评分**：0–100，分六项——五行流通 20 / 用神有力 25 / 格局清浊 20 /
调候寒暖 10 / 神煞吉凶 10 / 行运辅成 15，换算为上上→下下七档评级。

**综合断验**：性格（十干性情 + 十神主导 + 神煞特征）、事业（行业方向由用神五行
导出）、财运（财身关系、食伤生财、比劫夺财、财星宫位）、婚姻（配偶星 + 配偶宫 +
神煞）、健康（五行偏枯 → 脏腑、忌神当权）、六亲、子女、学业，以及开运建议
（方位/颜色/行业/数字/季节/作息/合作宜忌）。

## 6. 代码示例

```python
from bazi import cast_pillars, wu_xing_balance, day_master_strength, useful_god
from datetime import datetime

fp = cast_pillars(datetime(1990, 5, 12, 14, 30), "男", longitude=116.4)
print(fp.ganzhi, fp.lunar_date, fp.xunkong)
print(fp.shishen_map(), fp.zanggan_shishen(), fp.changsheng_map())
print(fp.relations())

power = wu_xing_balance(fp); st = day_master_strength(fp)
p = useful_god(fp, st, power)
print(p.name, p.yongshen, p.xishen, p.jishen, p.notes)
```

from bazi import solar_to_lunar, lunar_to_solar, terms_of_year

from bazi import BaziChart, destiny_poem, chart_rating

## 7. 已知边界与可扩展点

* **年份范围**：农历转换限 1899-02-10 – 2100-12-31（年表范围）。八字排盘本身
  不依赖年表，可排任意年份（1711 年命例已验证），但**真太阳时之外的农历显示**
  会缺省为 `—`。
* **调候**：本实现用规则化的「寒暖燥湿」判断（冬生喜火、夏生喜水、金寒喜火炼、
  木旺喜金裁），未内置《穷通宝鉴》120 条逐条表；替换 `pattern.tiaohou` 即可接入。
* **神煞流派差异**：天乙贵人、羊刃（阴干取法）、童子煞等流派分歧处已在代码注释中
  标注所采版本，便于按需替换。
* **断语风格**：结论都由十神/宫位/旺衰/神煞规则推出，凶象一律给出化解方向，
  不做绝对断言——命理是参考系，不是判词。
* **扩展方向**：紫微斗数（需农历 + 安星诀）、六爻/奇门（需另立盘式）、
  合婚（双盘交互）均可在此结构上以独立模块追加。
