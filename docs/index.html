它是什么

一个只做历法与排盘算法的 Python 库/CLI。节气由太阳视黄经实时推算（1900–2050 对照 JPL DE441 偏差 ≤1 分钟）， 农历据权威朔望月年表逐日往返零误差；支持出生地真太阳时换算与跨日子时自动换日柱，并输出格局用神、神煞、大运流年。 随包附带 MCP server，可直接挂到 Claude Desktop 等 AI 客户端。
本项目是历法/算法工程，命理内容为民俗文化研究，不做命运预测。

快速开始

pip install bazi-chart

# 文本命书（真太阳时按出生地经度）
bazi chart 1990-06-15 08:00 -g 男 --lon 117.0

# JSON 结构化排盘
bazi chart 1990-06-15 08:00 -g 男 --lon 117.0 --json --brief

# 农历 → 公历；二十四节气
bazi solar 1981 11 3
bazi terms 2026

# 自检（节气/农历/遁法/边界共 41 项）
bazi verify

MCP：挂到 AI 助手

启动命令 bazi-mcp（或 python -m bazi.mcp_server），stdio JSON-RPC，零依赖。 Claude Desktop 配置： 
{
  "mcpServers": {
    "bazi": { "command": "bazi-mcp" }
  }
}
暴露 4 个工具，只返回确定性排盘事实，吉凶解读交给模型：
bazi_chart 四柱+大运+格局 bazi_liunian 流年 bazi_liuyue 十二流月 bazi_lunar 农历互转

作为库使用

from bazi import BaziChart

c = BaziChart(1990, 6, 15, 8, 0, gender="男", longitude=117.0)
print(c.four_pillars.ganzhi)          # 四柱干支
print(c.pattern.name, c.pattern.yongshen)   # 格局、用神
print([d.name for d in c.dayun])      # 大运
print(c.liunian(2026).relations)      # 某流年与原柱关系
import json; print(json.dumps(c.to_dict(), ensure_ascii=False))

适用 / 不适用

适合
· Python 后端 / 内网 / 树莓派离线排盘
· 给 AI Agent 提供准确八字数据
· 需要真太阳时与海外跨日场景
· 二次开发（JSON + 分层 API）
不包含
· 紫微斗数 / 奇门 / 六爻（专注四柱）
· 在线算命网站 / SaaS
· 命运预测结论（只给事实与传统规则标签）
