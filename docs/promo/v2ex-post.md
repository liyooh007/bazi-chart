## 正文

自己用 Python 从零写的一套四柱排盘引擎，最想解决的是很多开源库的共同痛点：**把输入时间直接当当地时间，忽略真太阳时，海外出生不会自动跨日换日柱**。节气也不查硬编码表，而是用 VSOP87D 太阳视黄经实时求解，并和 JPL DE441 星历逐点对表。

### 为什么自己写

最近在研究中国传统历法，发现一个旧金山出生的案例很典型：按北京时间输入早上 7 点，换算到当地真太阳时其实是**前一天下午**，日柱应当整体重算；但不少库直接用输入时间，日柱就算错了。

于是决定从天文层重写，而不是 fork 现成农历库：

1. **节气实时算**：VSOP87D 地球日心黄经截断级数（L0–L5 共 129 项）+ IAU1980 章动主项 + 光行差 + ΔT（Espenak & Meeus），再用割线迭代求太阳视黄经过 15° 整数倍的时刻，收敛到 1e-9 度（约 1 毫秒）。
2. **真太阳时**：均时差 + 经度时差，东经西经都支持；校正结果落到前一天时，年柱（立春）、月柱（交节）、日柱（23 点/0 点可切换）、时柱一起重算。
3. **农历**：1899–2100 权威朔望月年表，含闰月（含 2033 闰十一月这种坑），73000+ 天公历↔农历往返零误差。

**精度实测**：1900–2050 共 240 个节气点对照 JPL DE441 数值历表，最大偏差 ≤ 1 分钟；外推到 2100 年因 ΔT 模型分歧最大约 3 分钟。

### 上层做了什么

纯历法只是地基，项目把传统子平那套也规则化了，并且刻意**多流派并列、不装作唯一正确**：

- 四柱、藏干、十神、纳音、十二长生、旬空、刑冲合害三合三会
- 五行力量量化、日主旺衰、扶抑用神 + 《穷通宝鉴》调候 + 《子平真诠》格局成败/官杀混杂/真假从格
- 神煞 40+、大运（顺逆排，起运精确到小数岁）、流年、流月
- 七言八句命理诗（每句可回溯到命盘字段）+ 0–100 综合评分
- CLI / Python API / JSON / **MCP server** 四种用法；零第三方依赖，树莓派离线可跑

一个刻意的边界：**MCP 只返回确定性排盘事实，吉凶解读交给宿主大模型**，项目本身不做"预测"。

### 和现有库的差异

lunar-python / lunar-javascript 是非常优秀的历法基石，很多项目直接依赖它们；我没有重复这条路，而是：

- 独立实现天文历法（差异化的根），
- 把上层子平推理做完整（多数库到干支层为止），
- 再用 **MCP + Pyodide + PyPI** 三种现代分发方式，让 AI 和网页都能零成本接入。

对比表和技术细节都在 README：https://github.com/liyooh007/bazi-chart

### 技术上欢迎拍砖

比起"准不准"，我更希望历法/天文方向的朋友来挑硬伤：

- 跨年、节气交界、子时、海外西经跨日这些边界，欢迎拿命例来对；
- VSOP87 截断项数、章动只取主项、ΔT 外推这些取舍我都写在代码注释和 docstring 里了；
- 命理规则各派不同，项目把分歧做成"备选格局并列输出"，也欢迎讨论怎么呈现更不误导。

在线 Demo 是纯静态页（Pyodide 直接加载 wheel），手机上也能开。觉得有点意思的话，求个 Star，也欢迎 Issue。
